# Сайт КП УЗН Деснянського району

Сайт-визитка комунального підприємства «Управління зеленого насадження Деснянського району» м. Києва. Публичная часть — Astro на GitHub Pages; бэкенд и админка — версия 2 (Node.js и Fastify на Render, MongoDB Atlas).

Требования — ТЗ в базе знаний проекта (версия 3.0). Состояние разработки — `docs/project-context.md`. Правила работы агента — `CLAUDE.md`.

## Запуск

Нужен Node.js версии из `.nvmrc` (26, активная LTS; минимум 22.22.0).

```sh
npm ci
npm run prepare
npm run dev
```

`npm run prepare` ставит git-хук pre-commit. Он вызывается отдельной командой потому, что в `.npmrc` стоит `ignore-scripts=true`: npm не выполняет никакие скрипты пакетов, включая свои собственные.

Сайт в режиме разработки открывается по адресу, который печатает `astro dev`, с базовым путём из `PUBLIC_BASE_PATH` (по умолчанию `/uzn-desna`).

## Команды

| Команда                 | Что делает                                       |
| ----------------------- | ------------------------------------------------ |
| `npm run dev`           | Режим разработки                                 |
| `npm run build`         | Сборка сайта в `site/dist`                       |
| `npm run preview`       | Просмотр собранного сайта                        |
| `npm run ci`            | Все проверки подряд — то же, что в CI            |
| `npm run typecheck`     | Типы по всем пакетам, `astro check` для страниц  |
| `npm run lint`          | ESLint, включая запрет импортов между слоями     |
| `npm run format`        | Prettier, правка файлов                          |
| `npm run test`          | Vitest                                           |
| `npm run data:check`    | Проверка файлов `data/*.json` схемой и конвертом |
| `npm run budget:check`  | Сверка веса первого экрана с бюджетом            |
| `npm run secrets:check` | Поиск имён и образцов секретов в сборке          |

## Рабочее пространство

| Пакет     | Что внутри                                               |
| --------- | -------------------------------------------------------- |
| `shared`  | Схемы Zod, типы, чистые функции формата                  |
| `site`    | Страницы Astro, компоненты, стили, шрифты, позже админка |
| `server`  | API бэкенда версии 2                                     |
| `scripts` | Проверки сборки, позже синхронизация источников          |

Данные публичных страниц лежат в `data/*.json`, изображения и документы — в `media/`.

## Секреты

В репозитории нет и не будет ни одного значения секрета: репозиторий публичный. Переменные версии 2 задаются в настройках Render и в секретах Actions, образец имён — `.env.example`.
