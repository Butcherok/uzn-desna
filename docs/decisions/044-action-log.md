# 044: Журнал действий в админке

Дата: 2026-11-22
Статус: принято

## Вопрос

Как владелец читает журнал действий (ТЗ 9.7): что пишется, как фильтруется и
как выглядит запись для человека без технических навыков. Запись в журнал уже
шла с 5а (вход, правки, загрузки, публикация); не было чтения и нескольких
событий.

## Решение

Ответы Заказчика 22.11.2026 — «по рекомендациям»; ТЗ 3.35, 9.7.

1. **`GET /log`** — только владелец (9.1): `user` (идентификатор или `none` —
   записи без пользователя), `from`, `to` (календарные дни по Киеву,
   `to` включительно), `page`. Ответ — 50 записей, новые первыми, имя
   пользователя вместо идентификатора, число записей и страниц, перечень
   пользователей для фильтра. Неверная дата — 422 с полем, а не пустой список.
2. **Только чтение.** Других методов у `/log` нет; чистка — индекс TTL 180 дней
   (5а).
3. **Неизвестный логин** пишется как `auth.login`, `denied`,
   `reason: unknown-login`, без введённого текста и без пользователя: в поле
   логина иногда вводят пароль.
4. **Название записи в деталях.** Создание, правка, смена состояния, кошик,
   восстановление и окончательное удаление записи контента пишут `title`
   (украинское название, до 120 знаков): журнал читается без открытия записи,
   а после окончательного удаления записи открыть уже нечего.
5. **Админка.** «Журнал дій» в группе «Службове», только у владельца.
   Действие, причина, стан и поля — словами; раздел — как в меню; название
   записи — ссылкой на неё, если запись ещё существует. Фильтр формой с кнопкой
   «Показати», страницы «Новіші» / «Старіші».

## Отброшено

- Показ введённого логина при неудачном входе: в журнал попал бы пароль.
- Бесконечная прокрутка: страницы проще для клавиатуры и экранного диктора.
- Фильтр по виду действия: в ТЗ его нет, при одном работающем человеке журнал
  короткий. Добавляется отдельной задачей, если понадобится.

## Последствия

- Старые записи контента — без `title`: у них в журнале виден идентификатор.
- Подписи действий живут в `admin/src/domain/log.ts`: новое действие без
  подписи показывается кодом — его надо добавить туда же (так будет с
  `backup.start` в 5ж3, подпись уже заведена).
