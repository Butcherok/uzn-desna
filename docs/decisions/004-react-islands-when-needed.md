# 004: Интеграция React включается с первым островом

Дата: 2026-11-13
Статус: принято

## Вопрос

Включённая интеграция `@astrojs/react` кладёт в сборку клиентский рантайм React — 220 КБ, 66,5 КБ после сжатия, — даже когда ни одна страница не содержит острова. Это больше бюджета JavaScript публичной страницы (50 КБ, ТЗ 11.2) целиком.

## Решение

Зависимости `react`, `react-dom` и `@astrojs/react` установлены, но в `site/astro.config.mjs` список `integrations` пуст. Интеграция включается в задаче, где появится первый остров — предпросмотр карточек в админке (ТЗ 9.3).

Шаг `budget:check` при этом считает только файлы, которые страница действительно запрашивает, и выводит отдельной строкой файлы сборки, на которые не ссылается ни одна страница.

## Отброшено

- **Оставить интеграцию включённой** — в сборке лежал бы файл, который никто не загружает; это противоречит «ничего лишнего в загрузке первого экрана» и рекомендации GitHub Pages держать сайт в пределах 1 ГБ.
- **Убрать React из зависимостей вовсе** — он нужен версии 2 по ТЗ 10.1 и 9.3; удаление означало бы вторую правку стека.

## Последствия

Пока островов нет, JavaScript на публичных страницах — 0 КБ. Включение интеграции в версии 2 обязано сопровождаться проверкой бюджета 11.2 на страницах, где остров появится.
