# 001: Сборщик — Astro с React-компонентами и TypeScript

Дата: 2026-11-13
Статус: принято

## Вопрос

На чём собирать публичную часть, чтобы страницы открывались при спящем бэкенде, держали бюджет первого экрана 500 КБ и работали с выключенным JavaScript.

## Решение

Astro, компоненты на React, TypeScript. Версия Astro на момент PR — 7.4.11.

Причины: HTML без JavaScript по умолчанию; острова React только там, где нужны; штатные `build.format: 'directory'`, `trailingSlash: 'always'`, `base` из переменной окружения, i18n с префиксом `/en/`; `404.html` страницей `src/pages/404.astro`.

## Отброшено

- **Eleventy** — ноль JS и отдельные адреса даёт, но React-компонентов нет, поэтому предпросмотр карточки в админке теми же компонентами, что на сайте (ТЗ 9.3), требует дублирования вёрстки.
- **Next.js со статическим экспортом** — требование 9.3 закрывает, но клиентский рантайм React едет на каждую публичную страницу при бюджете 50 КБ JS.
- **Чистый Vite + React как одностраничное приложение** — нет отдельных адресов и рабочего `404.html`, первый экран без JS не отображается.
- **Vite с пререндером** — всё перечисленное пришлось бы писать самостоятельно.

## Последствия

Версии зависимостей живут в `package-lock.json`, не в ТЗ. Мажорные версии Astro выходят примерно раз в год и требуют прогона по руководству обновления.
