# 039: Поисковая оптимизация до снятия закрытия

Дата: 2026-11-20
Статус: принято

## Вопрос

Аудит `docs/knowledge-base/13_seo-audyt.md` (задача вне очереди, 20.11.2026)
нашёл расхождения сборки с ТЗ 11.4 и противоречие в самом 11.4. Что исправить
сейчас, пока сайт закрыт, чтобы PR снятия закрытия свёлся к переключателю,
`robots.txt` и `sitemap.xml`?

## Решение

Ответы Заказчика 20.11.2026, правка ТЗ 3.30:

- **Адрес — `butcherok.github.io/uzn-desna`.** Доступа к DNS сети
  Київзеленбуду нет; свой домен не берётся. Заглушка 1 закрыта. Чего на адресе
  в подкаталоге нет (свой `robots.txt`, название сайта в выдаче, доменный ресурс
  Search Console) — отчёт 13, раздел 4.
- **Одна настройка индексации.** `INDEXING_ENABLED` в `site/src/config/site.ts`.
  Пока `false` — `noindex, nofollow` везде (ТЗ 3.3). После снятия — `noindex,
follow` только у страниц с `indexable={false}`: 404 и «Новини» (лента —
  чужие публикации).
- **`robots.txt` бэкенда разрешает обход**, из индекса сервис убирает
  `X-Robots-Tag: noindex, nofollow`. Google видит `noindex` только у
  страницы, которую ему разрешено обходить.
- **404 без `canonical` и `og:url`:** GitHub Pages отдаёт её на любой адрес.
  Своё `description`, не повтор `title`.
- **`title` главной** — «КП УЗН Деснянського району — озеленення й догляд»
  (проп `title` оболочки); остальные страницы — по формуле ТЗ 11.4.
- **`og:site_name`** на всех страницах.
- **Разметка `GovernmentOrganization` на главной** — `site/src/domain/organization.ts`.
  Подтип `Organization` по практике GOV.UK; поля — распознаваемые Google и
  только из `data/*.json` и `config/site.ts`; ЄДРПОУ в `taxID` (податковий номер
  юрособи — наказ Мінфіну № 1588, розд. II, п. 2.2); знак — `logo-512.png`,
  растеризован из `favicon.svg` (Google: не меньше 112×112). Нет данных —
  поля нет. `WebSite` не выводится: название сайта Google для подкаталога не
  поддерживает. Тег `application/ld+json` не исполняется, CSP его не касается.
- **Шаг `seo:check` в CI** после `budget:check`: длина `title` (60) и
  `description` (160) по кодовым точкам, повторы, `og:*` равны `title` и
  `description`, канонический адрес, `noindex` по настройке, разбор `JSON-LD`.
- **Три `description` сокращены** до предела: «Послуги», «Куди звертатися»,
  «Наші закупівлі».

## Отброшено

- Свой поддомен сети или платный домен — нет доступа к DNS, бюджет 0 грн.
- `taxID` + отдельный `identifier` с ЄДРПОУ — дублирование одного значения.
- `LocalBusiness` — предприятие не точка продаж.
- Ссылка на «Київзеленбуд» как `parentOrganization` — подчинение по данным
  «Баланса» могло смениться (`docs/findings.md`), не подтверждено.

## Последствия

PR снятия закрытия: `INDEXING_ENABLED = true`, `robots.txt` сайта (на адресе в
подкаталоге не действует, но вреда нет), `sitemap.xml` без 404 и «Новин»,
Lighthouse SEO в приёмку, шаги Search Console владельцем — отчёт 13, раздел 5.
