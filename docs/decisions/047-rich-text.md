# 047: разметка текста в полях — свои знаки, кнопки над полем

Дата: 2026-11-23
Статус: принято

## Вопрос

ТЗ 9.8, п. 1: обычный текст плюс закрытый набор — полужирный, ссылка, список.
Набор хранится своей разметкой, а не готовым HTML, визуальный редактор не
применяется. Решение 040, п. 4 отложило набор отдельной задачей (5и). Нужно
выбрать знаки, поля, способ ввода для сотрудника без технических навыков и что
делать со ссылками на почту, которые ТЗ 5.4, п. 7 запрещает показывать
открытым `mailto:`.

## Решение

Ответы Заказчика 23.11.2026 — «да» на все рекомендации.

1. **Знаки.** `**жирний**`, `[текст](адреса)`, строка с `- ` — пункт
   маркированного списка одного уровня; `• ` (так приходит список из Word) —
   тоже пункт. Абзац — непустая строка, как и до разметки: текст без знаков
   выводится теми же абзацами. Разбор — `shared/src/format/rich-text.ts`, общий
   для сайта, админки и сервера.
2. **Поля** — все шесть многострочных: «Довідка про підприємство»
   (`infoReference`), «Біографія» (`bio`), «Опис» послуги (`summary`), «Що ми
   робимо» (`whatWeDo`), «Вимоги» вакансии (`requirements`), «Текст» блока
   страницы (`text`). `whatWeDo` сайт сейчас не выводит (решение Заказчика
   16.11.2026): разметка в нём принимается и проверяется, чтобы правило было
   одно.
3. **Ввод — кнопки над полем:** «Жирний», «Посилання», «Список» вставляют знаки
   в текст (`admin/src/domain/rich-edit.ts`), Ctrl+B и Ctrl+K (и в украинской
   раскладке). Повторное нажатие снимает полужирный и пункт. Подписи словами,
   цель 44 px. Вид показывает карточка предпросмотра (решение 046); у
   «Підприємства» и «Текстів сторінок» карточки нет — там образец под полем,
   только когда в тексте есть разметка.
4. **Ссылки.** Принимаются `https://`, `http://` (с доменом), `tel:` (цифры),
   `mailto:` (адрес) — ТЗ 9.8, п. 2. Отказ — и в форме, и на сервере: схема
   `richLangText` в `shared`, текст по-украински с названием ссылки; сервер
   отдаёт его как есть по признаку `params.ui`. Ошибка английского текста
   начинается с «Англійською:» и показывается на закладке «Українська», куда
   форма и так переводит при ошибке.
5. **Почта** в ссылке выводится числовыми HTML-сущностями (решение 008): React
   экранировал бы сущности, поэтому такая ссылка вставляется готовой разметкой,
   целиком из сущностей.
6. **Решения разработчика:** незакрытые `**`, скобки без адреса и запрещённая
   ссылка выводятся как набраны; ссылка открывается в той же вкладке; предел
   длины считается вместе со знаками; английский — с той же разметкой.

## Отброшено

- **Только подсказка без кнопок** — сотруднику пришлось бы помнить знаки.
- **Визуальный редактор** — прямо запрещён ТЗ 9.8, п. 1: чужие стили, вставка
  из Word, разметка вне дизайн-системы.
- **Markdown целиком (библиотека)** — заголовки, картинки, таблицы, HTML внутри:
  набор перестаёт быть закрытым, а отсекать лишнее дороже, чем разобрать три
  знака.
- **Нумерованные и вложенные списки** — не просили, в данных не встречаются.
- **Запрет почты в полях** — житель потерял бы ссылку там, где её поставил
  редактор; кодирование уже есть (решение 008).

## Последствия

- `paragraphs` (`site/src/domain/text.ts`) удалён: абзацы даёт `RichText`.
- Вывод — `site/src/components/cards/RichText.tsx`: карточки послуги, вакансии,
  руководителя, страницы «Про підприємство», «Публічна інформація», «Новини»,
  «Наші закупівлі». Сборка без разметки совпадает с прежней побайтно, кроме
  `&#39;` → `&#x27;` (так экранирует React, как в 5з1).
- Опубликованные данные (`content-data`, 23.11.2026) знаков не содержат: старые
  тексты не меняются.
