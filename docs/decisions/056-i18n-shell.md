# 056: двуязычная оболочка сайта

Дата: 2026-11-27
Статус: принято (английское название — вариант 2, ждёт утверждения Заказчиком)

## Вопрос

Версия 3, задача 2 (`claude/16_plan-versii-3.md`, раздел 3, строка 2): язык как параметр оболочки, маршруты `/en/…`, переключатель `UA / EN`, подписи интерфейса на двух языках, правило «нет перевода — нет страницы» и проверка «английского не больше украинского» (Закон № 2704-VIII, ст. 27 ч. 6, https://zakon.rada.gov.ua/laws/show/2704-19). Английские тексты страниц в задачу не входят: это задача 3 (В4).

## Решение

Все решения Заказчика 27.11.2026 приняты по рекомендациям (ТЗ 3.48).

1. **Язык — параметр оболочки.** `BaseLayout` принимает `lang`: `html lang`, `og:locale` (`uk_UA`, `en_GB`) и `og:locale:alternate`, канонический адрес своей версии, `og:site_name`, `og:image:alt`. Путь страницы передаётся без языкового префикса, префикс добавляет `i18n/lang.ts` (`localizedPath`).
2. **`hreflang`** (`uk`, `en`, `x-default` на украинскую) — только у страницы, у которой есть обе версии. У страницы без перевода `hreflang` нет вовсе (ТЗ 3.2, п. 6; 12.4 исправлен).
3. **Тексты.** Подписи оболочки — словарь `i18n/ui.ts`: тип общий для обоих языков, поэтому подпись без перевода не проходит проверку типов. Тексты страниц — `i18n/copy/<страница>.ts`, у каждого `uk` и необязательный `en`. Разметка четырёх страниц — `views/*View.astro` с параметром `lang`; `pages/<раздел>/index.astro` выводит украинскую версию, `pages/en/[...section].astro` — английские.
4. **«Нет перевода — нет страницы».** Английская страница собирается, только если у неё есть `en` в `i18n/copy` и у **каждого** украинского текста данных, который она выводит, есть `en` — вместе с подвалом (`domain/translation.ts`). Частичная страница не собирается. Без английской главной не собирается ни одна английская страница: переключателю со страниц без перевода некуда было бы вести. Перечень собранных английских страниц — одно место, `i18n/availability.ts`: его читают маршрут, меню, переключатель, `hreflang` и 404.
5. **Переключатель `UA / EN`** — обычные ссылки без JavaScript, в полосе шапки перед кнопкой меню. Английской версии нет — переключателя нет. На странице без перевода — ссылка на `/en/`. Уже 480 px выводится только ссылка на другой язык. ДС 1.19.
6. **Английская версия:** главная, «About us», «Services», «Contact us» (ТЗ 4.13). Новости, лента, закупки, вакансии, публичная информация и «Заява про доступність» не переводятся. В английском меню и на главной их нет; блока «Новини» на английской главной нет. Ссылки подвала на украинские страницы и сайты — с `hreflang="uk"` и пометкой «(in Ukrainian)».
7. **404** — одна страница на оба языка (GitHub Pages отдаёт её и на `/en/…`): украинский блок и полный английский в `lang="en"`. Пока английской главной нет, английские ссылки ведут на украинские страницы и прямо это говорят.
8. **Числа и даты по-английски** — британская запись: `1,116.6`, `09/01/2002` (`formatCount`, `formatHectares*`, `formatDate` получили необязательный `lang`, по умолчанию украинский).
9. **Шаг `lang:check`** (`scripts/src/lang/check.ts`) в `npm run ci` и в `Deploy` — на опубликованных данных. Правила:
   - `html lang` у каждой страницы верный;
   - у английской страницы есть украинская пара;
   - английских страниц не больше, чем украинских;
   - видимого текста в `main` английской страницы не больше по знакам, чем у её украинской пары;
   - на английской странице нет кириллицы вне `lang="uk"` (непереведённые подписи);
   - `hreflang` соответствует правилу п. 2;
   - ни одна ссылка не ведёт на несобранную `/en/…`.

   Сверка по сущностям держится схемой: `en` существует только рядом с `uk` (ТЗ 6.1, п. 4), и п. 4 выше.

10. **Английское название** (на утверждение): короткое «Desnianskyi Green Spaces», полное — «Desnianskyi District Green Spaces Maintenance Enterprise, a municipal enterprise owned by the City of Kyiv». Транслитерация — постанова КМУ № 55. Меняется одной строкой в `i18n/ui.ts`.

## Отброшено

- **`hreflang` uk + `x-default` на каждой украинской странице без перевода.** Ссылается только на себя и ничего не даёт.
- **Английская страница со скрытыми непереведёнными блоками.** Противоречит ТЗ 4.13: перевод требуется для каждого опубликованного текста. Страница показала бы не то, что утверждено.
- **`/en/news/` с новостями в оригинале** (12.4 до 3.48). Расходилось с составом 4.13.
- **Переключатель, ведущий на `/en/` до появления английской главной.** Вёл бы на 404.
- **Сборка с тестовыми английскими данными в CI.** Данные подключаются статическим импортом; подмена ради CI трогала бы `data/`. Правила проверки покрыты модульными тестами на синтетическом HTML. Живая английская сборка появляется в задаче 3 и проверяется тем же шагом.
- **Названия «ME UZN …» (буквальное) и «… Parks & Open Spaces».** Первое англичанину ничего не говорит, второе сужает дело до парков. «… Ltd» — ложная форма для коммунального предприятия.

## Последствия

- На текущих данных английских страниц ноль. Украинские страницы собираются байт в байт как до задачи, кроме адреса файла CSS. Изменилась только 404.
- Задача 3 вписывает `en` в `i18n/copy/*.ts` и вводит переводы данных через админку. Страницы появятся сами, когда переведено всё, что они выводят.
- Текст ст. 27 ч. 6 сверен по пересказу (kodeksy.com.ua), а не по официальному тексту: rada.gov.ua закрыт для инструментов разработчика (`claude/04_vymohy.md`, «[ПРОВЕРИТЬ]»).
