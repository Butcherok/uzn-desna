# 030: КМДА исключена из ленты

Дата: 2026-11-20
Статус: принято

## Вопрос

Что делать с источником КМДА, который раннерам GitHub отвечает проверкой
Cloudflare (403) и выключен с 20.11.2026 (решение 027).

## Решение

Источник исключён из белого списка ленты (решение Заказчика 20.11.2026: «то что не
работает не используем»; «полно других открытых ресурсов с новостными
лентами»). ТЗ 3.23: 4.8, 7.4. В `data/feed-rules.json` запись остаётся с
`enabled: false` и пометкой «Виключено рішенням Замовника (рішення 030)».

## Отброшено

- **Обход проверки Cloudflare** — не делаем (решение 027).
- **Повторная проверка позже** — источник больше не ждём.

## Последствия

- Код запасного пути (`scripts/src/sync/feed/sources.ts`) и значение `kmda` в
  схеме не удаляются в этом PR: они выключены данными и ничего не делают.
  Удаление — отдельной уборкой, записано в `docs/findings.md`.
- Новые источники вместо КМДА — отдельной задачей по решению Заказчика, по
  правилам отчёта 08 (правовая рамка — раздел 5).
