# 002: Репозиторий публичный, деплой на GitHub Pages

Дата: 2026-11-13
Статус: принято

## Вопрос

Репозиторий был создан приватным и назывался `uzn-desna-site`, а ТЗ и инструкции проекта предполагают публичный `uzn-desna`.

## Решение

Репозиторий переименован в `uzn-desna` и сделан публичным.

Проверено по документации GitHub 13.11.2026: на тарифе Free GitHub Pages доступен только в публичных репозиториях; защищённые ветки и наборы правил на Free — тоже только в публичных; стандартные раннеры Actions бесплатны для публичных репозиториев, а для приватных плата начинается после израсходования включённого объёма (на Free для личного аккаунта — 2 000 минут в месяц).

## Отброшено

- **Оставить приватным и купить GitHub Pro** — ломает бюджет 0 грн и правило «только бесплатные тарифы» (ТЗ 1.2).
- **Оставить имя `uzn-desna-site`** — потребовало бы правок в ТЗ 1.1, 10.3, 10.5, 13.3, в инструкциях проекта и в `CLAUDE.md` без выгоды.

## Последствия

Публичность — не предпочтение, а условие работоспособности: без неё нет ни деплоя, ни защиты `main`. Отсюда же строгость к секретам (ТЗ 10.5) и необязательность согласий на фото уже на внутреннем показе (ТЗ 3.3).
