# 050: вёрстка по замечаниям к версии 2 — шапка, отступы, телефоны, часы, подвал

Дата: 2026-11-26
Статус: принято

## Вопрос

Замечания Заказчика после просмотра сайта на разных ширинах
(`claude/14_zamechaniia-v2.md`, пп. 1, 5–8): шапка уезжает при прокрутке;
отступы неровные («Детальніше» у края карточки); рамка телефона растянута во
всю ширину; «обідня перерва» и часы одной строкой; строка «Інформація
оновлена» живёт отдельно, а её дата — константа `2026-11-17` в коде.

## Решение

Ответы Заказчика 26.11.2026 — «по рекомендации» (ТЗ 3.41, дизайн-система 1.14).

1. **Шапка липкая** (`position: sticky`), без JavaScript. На `html` —
   `scroll-padding-top` = высота шапки + 16 px: якорь и элемент в фокусе под
   шапку не уходят (WCAG 2.2, 2.4.11). Отброшены: прятать при прокрутке вниз —
   нужен JavaScript; уменьшать при прокрутке на scroll-driven animations —
   работает не во всех браузерах.
2. **Правило отступов — четыре уровня**: `--s-2`, `--card-pad` (16/20/24),
   `--stack` (16/16/20), `--section`. Блоки внутри `main` стоят на полях
   (`margin`), которые схлопываются, — между соседями ровно `--section` вместо
   прежних двух `padding` (96 px на десктопе). `h2`/`h3` не первым — сверху
   `--section`; `h1` снизу 32 px, блок под ним без верхнего поля.
3. **Причина «Детальніше» у края**: `.card > :last-child { margin-bottom: 0 }`
   обнулял нижнее поле ряда ссылок. Нижнее поле карточки ленты — её `padding`.
4. **Кнопка-телефон** с 600 px — `width: fit-content`, не уже 18 rem и не шире
   колонки; до 600 px — во всю колонку (тач-цель).
5. **Часы строками.** Поле «Години роботи» в админке многострочное; сайт
   выводит строку данных строкой (`textLines` в `shared`). «Сб, Нд — вихідні»
   убрано из кода главной и «Контактів» — оно теперь в данных. Текст
   «Перерва 12:00–13:00» вводит Заказчик в админке: опубликованные данные живут
   в ветке `content-data`, правка `data/contacts.json` в `main` — только
   начальные данные.
6. **Нижняя полоса подвала**: «© <год> … Усі права захищено.» · «Оновлено
   <дата>» · «Розробка — S#RP» (без ссылки). Дата — `contentUpdatedAt`: самая
   поздняя `generatedAt` файлов выгрузки админки, без файлов синхронизации
   (лента и закупки обновляются сами и меняли бы дату ежедневно). Год и дата —
   по киевскому времени. Константа `CONTENT_UPDATED_AT` удалена.

## Последствия

- До ввода новых часов в админке сайт показывает прежнюю строку
  «Пн–Пт 08:00–17:00, обідня перерва 12:00–13:00» без «Сб, Нд — вихідні».
- «Куди звертатися» и колонка дежурного в подвале не тронуты: их убирает ветка
  объединения контактов.
- Для `lastmod` в `sitemap.xml` (findings) теперь есть дата из данных.
