# 057: анимированный переключатель языка

Дата: 2026-11-27
Статус: принято (Заказчик 27.11.2026 — «по рекомендациям», вариант 1); размер «таблетки» и ширина шапки заменены решением 058

## Вопрос

Заказчик 27.11.2026: надписи UA и EN — внутри переключателя, анимация обязательна. Ограничения: обычные ссылки без JavaScript (решение 056), цели не меньше 44×44 и 8 px между соседними (ТЗ 11.1, п. 4), при `prefers-reduced-motion` движения нет (ТЗ 11.3, п. 11), только токены, обе темы, повышенный контраст, `forced-colors`. Показаны три варианта на 320 и 1280 px в четырёх режимах и кадры анимации.

## Решение

1. **Сегментная «таблетка»** (`LangSwitch.astro`, ДС 1.20, раздел 7): две ячейки 44×44, рамка псевдоэлементом поверх. Текущий язык — текст с `aria-current` на тёмной подложке `--c-deep`, другой — ссылка `--c-mid` с `hreflang` и `lang`. Разметка и семантика решения 056 не меняются; косая черта и правило «уже 480 px — только ссылка на другой язык» сняты: обе ячейки видны всегда.
2. **Анимация без JavaScript — переход между страницами.** `@view-transition { navigation: auto; }` внутри `@media (prefers-reduced-motion: no-preference)`. Подложка — отдельный элемент `view-transition-name: lang-thumb`, надписи — свои слои (`lang-uk`, `lang-en`), иначе подложка проехала бы поверх них. Корень в переходе не участвует (`:root { view-transition-name: none; }`): страница меняется сразу, едет только подложка, 200 мс (`--motion-switch`). При переходе по меню подложка стоит на месте.
3. **Поддержка** — по данным MDN (`@mdn/browser-compat-data` 8.1.11, `css.at-rules.view-transition.navigation`): Chrome и Edge 126, Safari и Safari iOS 18.2, Firefox и Firefox Android 162. Запасной путь — сама навигация: браузер без поддержки переходит как обычно, новое положение подложки видно сразу. caniuse помечает Firefox 144–161 «частичной поддержкой» без пояснений — в Firefox живьём не проверено.
4. **Ширина шапки.** Знак 32 + 8, название 149,4, таблетка 88, меню 44, поля 2 × 16. До 1024 px промежутки полосы — `--tap-gap` (8 px): правило 1.19 давало 4 px между переключателем и меню, меньше 8 px из ТЗ 11.1, п. 4. Полное название входит от 370 px; 330–369 (в том числе 360) — без знака; уже 330 — знак и «КП УЗН», вторая строка скрыта, полное название остаётся в имени ссылки-логотипа. Правила действуют только при наличии переключателя (`:has(.lang-switch)`).
5. **Контраст:** в `contrast:check` добавлены пары «текущий язык на подложке» (`--c-bg` / `--c-deep`) и «подложка на фоне переключателя» (`--c-deep` / `--c-surface`).

## Отброшено

- **Вариант 2, тумблер одной ссылкой с обеими надписями в дорожке** (64 px). Одна цель на два языка: имя ссылки должно содержать «UA EN», текущий язык не отмечается `aria-current`. Выигрыш в ширине (полное название от 346 px) этого не перевешивает.
- **Вариант 3, ручка с надписью текущего языка** (60 px). На странице UA видимая надпись «UA», а ссылка ведёт на английскую версию: голосом «нажми UA» человек попадает на English — против смысла WCAG 2.5.3.
- **Анимация подложки по `@keyframes` при загрузке страницы** (работает во всех браузерах). Без JavaScript её нельзя отличить от обычной загрузки: подложка ездила бы при каждом переходе по английским страницам — самодвижение, запрещено ТЗ 11.3, п. 11.
- **Анимация через скрипт** (`pagereveal`). Решение 056 — переключатель без JavaScript; бюджет 11.2.
- **Перевести переключатель в меню на узком экране.** ДС 1.19, раздел 7: на телефоне виден всегда.

## Последствия

- Первое движение на сайте, которое не только цвет: ДС 1.20, раздел 10, п. 1 и п. 8; ТЗ 3.49, 11.3, п. 11.
- `@view-transition` включён на всех страницах: при любом переходе внутри сайта браузер на 200 мс держит снимок. Видимого движения нет, кроме подложки. Принимает ли браузер ввод в эти 200 мс — не замерялось.
- На текущих данных переключателя нет (английских страниц 0): украинские страницы собираются байт в байт как до задачи, кроме адреса CSS. Живая проверка — в задаче 3 вместе с английской главной.
