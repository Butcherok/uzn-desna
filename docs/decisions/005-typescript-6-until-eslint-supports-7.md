# 005: TypeScript 6 до поддержки TypeScript 7 в typescript-eslint

Дата: 2026-11-14
Статус: принято

## Вопрос

Dependabot предложил поднять TypeScript с 5.9.3 до 7.0.2 (актуальный выпуск). Прогон CI упал: `npm ci` обрывается ошибкой `ERESOLVE`, потому что `typescript-eslint@8.72.2` объявляет совместимость `typescript >=4.8.4 <6.1.0`.

## Решение

TypeScript поднят до 6.0.3 — самого нового выпуска, который `typescript-eslint` допускает. В `.github/dependabot.yml` добавлено правило игнорировать мажорные обновления `typescript`.

Проверено: `npm run ci` зелёный на TypeScript 6.0.3 с `typescript-eslint@8.72.2`, `eslint@10.15.0`, `astro@7.4.12`; `astro check` — 0 ошибок.

## Отброшено

- **Оставить TypeScript 5.9.3** — отказ от выпуска, который и так совместим, без причины.
- **Снять `typescript-eslint`** — он держит запрет импортов между слоями (ТЗ 10.2, п. 1) и правило против `any`.
- **Поставить TypeScript 7 с `--legacy-peer-deps`** — установка, которая расходится с объявленной совместимостью, ломается молча и в самый неудобный момент.

## Последствия

Правило в `dependabot.yml` снимается, когда `typescript-eslint` выпустит версию с поддержкой TypeScript 7. До тех мажорные обновления TypeScript не предлагаются, минорные и исправляющие приходят как обычно.
