# 055: «Новини» — новые источники, все карточки страницами

Дата: 2026-11-27
Статус: принято

## Вопрос

Замечания Заказчика к версии 2, пп. 13–14 (`claude/14_zamechaniia-v2.md`):
в ленте мало источников (Київзеленбуд и The Conversation, ≈0,75 карточки в
неделю), а над лентой второй заголовок «Новини галузі». Какие источники
добавить, как выводить ленту, если объём вырастет в десятки раз, и что
делать с выключенными КМДА и GDELT. Исследование кандидатов —
`claude/15_istochniki-novyn.md` (живой прогон 26.11.2026).

## Решение

Решения Заказчика 26–27.11.2026 (журнал ТЗ 13.3):

- **Источники.** Добавлены сайты КП УЗН сети «Київзеленбуд» — Деснянського
  (сайт самого предприятия: собственного блока новостей нет, решение 029),
  Подільського и Дніпровського районів — и Хмарочос (без письма редакции,
  риск принимает Заказчик). Перечень — `FEED_SOURCES` в
  `shared/src/schemas/feed.ts`. Пробный прогон на раннере 27.11.2026 (run
  `45952015119`, `dry_run`): все шесть адресов ответили `200`, вошло новых
  записей: Деснянський 61, Подільський 82, Дніпровський 73, Хмарочос 14;
  фото — 29 за прогон.
- **Словарь — для всех записей без тематического тега.** У сайтов сети рубрик
  по теме нет: их записи проходят словарь и основным путём (WordPress REST).
  Сохранённая запись, отсеянная словарём в очередном прогоне, уходит из файла
  (`rejected`). Это закрывает Ф1 отчёта 14: «Зимова підтримка» и
  «70 років…» ушли в пробном прогоне.
- **Отрывок.** Деснянський — да (свой сайт); Київзеленбуд и районные сайты —
  нет, как у головного (правила не опубликованы); Хмарочос — нет (любое
  использование — с разрешения редакции); The Conversation — да. Признак
  переключается в админке и действует на записи, полученные после этого.
- **Вывод.** Одна лента под h1 «Новини», без второго заголовка; все
  карточки по дате, новые первыми, без предела на источник; страницы по 24
  (`/news/`, `/news/2/`…), переключение ссылками «Новіші», «Старіші» и
  номерами, без JavaScript. Подпись ленты — под карточками мелким шрифтом.
  На главной — три последние под h2 «Новини».
- **Хранение — год** по дате публикации (`FEED_KEEP_DAYS`), предел файла 2000
  записей — защита от сбоя источника. WordPress — `per_page=100` за 180 дней.
  Фото — до 30 записей за прогон (было 12): при запуске ≈230 новых записей
  получают фото за 3 дня.
- **Правила ленты — из админки.** Синхронизация берёт `data/feed-rules.json`
  из ветки `content-data` (шаг `Take published feed rules`); до этого брала
  файл из `main`, и включение источника или уривка в «Словнику стрічки» до
  синхронизации не доходило.
- **Переход данных.** Схема приводит перечень источников к `FEED_SOURCES`
  (`normalizeFeedSources`): старые записи БД и файлы `content-data` проходят
  проверку, выбывшие источники отбрасываются, новые добавляются со
  значениями по умолчанию. Сервер при запуске один раз правит запись «Словник
  стрічки» (`2026-11-feed-sources`, журнал `content.patch`): перечень по
  `FEED_SOURCES`, Хмарочос включён. На сайт и в синхронизацию это уходит
  обычной публикацией из админки.
- **Админка.** Раздел «Новини галузі» → «Стрічка новин»; место карточки —
  «на головній і на 1-й сторінці «Новин»» или «в «Новинах», сторінка N».
- **Удалено.** Код и значения `kmda`, `gdelt` (схемы ленты и состояния
  синхронизации, подписи админки), `via: gdelt`.

## Отброшено

- **Предел «2 карточки одного источника на странице»** — Заказчик против
  урезания ленты.
- **Кнопка «Показати ще»** — догрузка без перезагрузки требует JavaScript на
  публичной странице (ТЗ 11.2: 0 КБ); страницы дают то же без потери карточек.
- **Голосіївський КП УЗН** — 11 из 29 записей не по теме; **Еврокомиссия,
  Urban environment** — ≈0,5 записи в неделю; **WRI**, **TheCityFix**
  (проверка Cloudflare), **UN-Habitat** (ленты нет), **GDELT** (429 и выдача
  не по теме) — исследование 15.
- **Хранить всё без срока** — файл и ветка `sync-data` росли бы без предела
  (≈680 записей и ≈58 МБ фото в год при нынешнем объёме).

## Последствия

- Объём ≈13 карточек в неделю против ≈0,75; лента в основном украинская.
- Ветка `sync-data` растёт на ≈1 МБ фото в неделю; файлы ушедших записей
  удаляются тем же коммитом, но история git их хранит.
- До публикации из админки после выкладки сервера синхронизация видит прежний
  файл правил: районные сайты включены по умолчанию, Хмарочос — нет.
