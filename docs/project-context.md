# Состояние проекта

Обновлено: 2026-11-26

## Что это

Сайт-визитка КП УЗН Деснянського району. Фронт: Astro + GitHub Pages. Бэкенд версии 2: Node.js и Fastify на Render Free. БД: MongoDB Atlas. Языки: uk (основной), en (версия 3). Админка (пакет `admin`: Vite, React) отдаётся с Render по `/admin/`, `/admin` на Pages её будит (решения 036, 040); публикация — рабочий процесс `publish-content` в ветку `content-data` (решение 041); учётная запись одна — владелец, роль «редактор» есть в модели, но не заведена. До решения руководства сайт закрыт от индексации.

Источник требований — ТЗ в базе знаний Claude (разделы 1–13 приняты 13.11.2026). Текущая версия 3.43; 26.11.2026 она загружена в базу знаний, и копия в `docs/knowledge-base/10_tz-sait.md` совпадает с мастером побайтно (`sha256` копии равен версии документа базы знаний). Дизайн-система 1.16 — отдельный документ базы знаний, тоже совпадает с копией. Копии девяти документов базы знаний лежат в `docs/knowledge-base/`; копия не мастер: при расхождении прав документ базы знаний (ТЗ 1.1, 10.3, п. 6).
