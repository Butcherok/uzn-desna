# Состояние проекта

Обновлено: 2026-11-19

## Что это

Сайт-визитка КП УЗН Деснянського району. Фронт: Astro + GitHub Pages. Бэкенд версии 2: Node.js и Fastify на Render Free. БД: MongoDB Atlas. Языки: uk (основной), en (версия 3). Админка с ролями «владелец» и «редактор». До решения руководства сайт закрыт от индексации.

Источник требований — ТЗ в базе знаний Claude (разделы 1–13 приняты 13.11.2026). Текущая версия 3.14; 19.11.2026 она загружена в базу знаний, и копия в `docs/knowledge-base/10_tz-sait.md` совпадает с мастером побайтно (сверено по контрольной сумме). Дизайн-система 1.9 — отдельный документ базы знаний, тоже совпадает с копией. Копии девяти документов базы знаний лежат в `docs/knowledge-base/`; копия не мастер: при расхождении прав документ базы знаний (ТЗ 1.1, 10.3, п. 6).

   если знак есть, затирать его нельзя.
