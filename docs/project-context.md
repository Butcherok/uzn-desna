# Состояние проекта

Обновлено: 2026-11-27

## Что это

Сайт-визитка КП УЗН Деснянського району. Фронт: Astro + GitHub Pages (`butcherok.github.io/uzn-desna`, закрыт от индексации до решения руководства). Бэкенд: Node.js и Fastify на Render Free, БД MongoDB Atlas. Админка (`admin`: Vite, React) отдаётся с Render по `/admin/`; публикация — рабочий процесс `publish-content` в ветку `content-data` (решения 036, 040, 041). Учётная запись одна — владелец. Языки: uk (основной), en (версия 3).

Требования — ТЗ в базе знаний Claude, версия 3.51. ТЗ и дизайн-система (1.22) хранятся частями: оглавление (`10_tz-sait.md`, `11_dyzain-systema.md`) и части до 80 КБ. Копии — `docs/knowledge-base/`, совпадают с базой знаний; при расхождении прав документ базы знаний (ТЗ 1.1, 10.3, п. 6). Закрытые документы — `docs/archive/`.
