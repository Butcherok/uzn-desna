## Что это

Сайт-визитка КП УЗН Деснянського району. Фронт: Astro + GitHub Pages. Бэкенд версии 2: Node.js и Fastify на Render Free. БД: MongoDB Atlas. Языки: uk (основной), en (версия 3). Админка отдаётся с Render, `/admin` на Pages её будит (решение 036); учётная запись одна — владелец, роль «редактор» есть в модели, но не заведена. До решения руководства сайт закрыт от индексации.

Источник требований — ТЗ в базе знаний Claude (разделы 1–13 приняты 13.11.2026). Текущая версия 3.29; 20.11.2026 она загружена в базу знаний, и копия в `docs/knowledge-base/10_tz-sait.md` совпадает с мастером побайтно (`sha256` копии равен версии документа базы знаний). Дизайн-система 1.13 — отдельный документ базы знаний, тоже совпадает с копией. Копии девяти документов базы знаний лежат в `docs/knowledge-base/`; копия не мастер: при расхождении прав документ базы знаний (ТЗ 1.1, 10.3, п. 6).

Сверка после загрузки — чтением документа обратно в файл и сравнением контрольных сумм: совпали. Так же проверять и впредь: `md5sum` копии и выгруженного мастера, а не «тул ответил успехом».
