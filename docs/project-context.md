# Состояние проекта

Обновлено: 2026-11-13

## Что это

Сайт-визитка КП УЗН Деснянського району. Фронт: Astro + GitHub Pages. Бэкенд версии 2: Node.js и Fastify на Render Free. БД: MongoDB Atlas. Языки: uk (основной), en (версия 3). Админка с ролями «владелец» и «редактор». До решения руководства сайт закрыт от индексации.

Источник требований — ТЗ в базе знаний Claude, версия 3.0 (разделы 1–13 приняты 13.11.2026). Дизайн-система 1.0 — отдельный документ базы знаний.

## В работе

Первый PR: каркас рабочего пространства, инструменты качества, CI, деплой, пустые страницы версии 1 с шапкой и подвалом.

## Сделано

- Рабочее пространство npm: `shared`, `site`, `server`, `scripts`.
- Строгий `tsconfig.base.json`, ESLint с запретом импортов между слоями, Prettier, Vitest, husky с pre-commit.
- `npm run ci` из восьми шагов: typecheck, lint, format:check, test, data:check, build, budget:check, secrets:check.
- Рабочие процессы `ci.yml` и `deploy.yml`, Dependabot, шаблон PR.
- Дизайн-система 1.0 в репозитории: `site/src/styles/tokens.css`, `components.css`, два шрифта в `site/src/fonts`, демонстрация в `docs/design/components.html`.
- Семь страниц версии 1 и `404.html`: шапка, меню на `details`, подвал, метаданные, `noindex`, канонические адреса.
- Тесты: обрезка текста по границе слова (ТЗ 5.2), формат и маска телефона (ТЗ 5.1, п. 6).

## Следующий шаг

Контент страницы «Куди звертатися» и «Контакти» — после получения от Заказчика телефонов сценариев и подтверждения телефонов (заглушки 14, 15, 17, 18 реестра ТЗ 13.2).

## Найдено попутно, не сделано

- `robots.txt` проекта лежит по адресу `/uzn-desna/robots.txt`, а поисковики читают его только в корне домена (`butcherok.github.io/robots.txt`). Для страниц проекта запрет из ТЗ 3.3, п. 2 так не работает; закрытие держится на `<meta name="robots">` на каждой странице. Решение за Заказчиком: отдельный репозиторий `butcherok.github.io` с корневым `robots.txt`, свой домен или оставить только `noindex`.
- Перенаправление адреса без завершающей косой черты (ТЗ 3.2, п. 3) задаёт GitHub Pages, локально не проверяется. Проверить на первом опубликованном деплое.
