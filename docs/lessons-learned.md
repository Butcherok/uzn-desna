# Уроки

Правило: симптом → что делать. 1–3 строки на урок. Перед добавлением проверить, нет ли уже.

| Симптом                                                                                                               | Делать                                                                                                                                                                                                                                                | Не делать                                                                |
| --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Исправление «не помогло»                                                                                              | Проверить, что открыта новая сборка: номер в подвале, кэш, проснулся ли бэкенд                                                                                                                                                                        | Следующая правка вслепую                                                 |
| Совет о внешнем сервисе по памяти оказался устаревшим                                                                 | Сверять с официальной документацией перед ответом                                                                                                                                                                                                     | Утверждать без проверки                                                  |
| Старый PowerShell не понимает `&&`                                                                                    | Команды отдельными строками                                                                                                                                                                                                                           | Цепочки через `&&`                                                       |
| Ошибка API превратилась в пустой список                                                                               | Три состояния: данные, пусто, неизвестно                                                                                                                                                                                                              | `catch` с пустым значением                                               |
| Приватный репозиторий на тарифе Free                                                                                  | Сделать публичным: иначе нет ни GitHub Pages, ни защиты `main`, ни бесплатных минут Actions                                                                                                                                                           | Платить за Pro при бюджете 0                                             |
| `robots.txt` проекта не действует                                                                                     | Для страниц проекта поисковики читают только корневой `robots.txt` домена; закрытие держать на `<meta name="robots">`                                                                                                                                 | Считать, что `/<проект>/robots.txt` что-то запрещает                     |
| Интеграция фреймворка кладёт рантайм в сборку без островов                                                            | Включать интеграцию в задаче, где появится первый остров; `budget:check` считает только запрошенные страницей файлы                                                                                                                                   | Держать в сборке файл, который никто не загружает                        |
| Версия зависимости или действия написана по памяти                                                                    | Брать номер из реестра пакетов и из страницы действия перед записью в `package.json` и в рабочий процесс                                                                                                                                              | Полагаться на номер, который помнишь: он отстаёт на мажорные версии      |
| Ссылка в чужом разделе названа по документу                                                                           | Открыть каждую и посмотреть, куда она ведёт: название пункта и адрес могут относиться к разным системам                                                                                                                                               | Переносить к себе список названий, не открыв ни одной ссылки             |
| Содержимое закрытого `details` не показывается стилем                                                                 | Браузеры прячут его через `::details-content { content-visibility: hidden }`; раскрывающееся меню строить на `popover`, `details` оставить для биографии                                                                                              | Перекрывать `display` у списка внутри закрытого `details`                |
| Встроенный браузер не открывает localhost контейнера                                                                  | Проверять вёрстку Chrome из контейнера (`/usr/bin/google-chrome`) через `puppeteer-core`: ширины, клавиатура, печать                                                                                                                                  | Выкладывать сборку артефактом ради проверки: панель требует входа        |
| Локально `npm run ci` зелёный, а CI красный                                                                           | Перед словом «готово» прочитать `.github/workflows/*.yml` целиком: в задаче есть шаги вне `npm run ci` (сейчас — `npm audit`), прогнать и их                                                                                                          | Считать, что `npm run ci` повторяет задачу CI полностью                  |
| Новый совет безопасности валит `audit`                                                                                | Сначала `npm view <пакет> versions` — есть ли вообще исправленная версия; затем проверить `--omit=dev` и `npm audit fix` и только потом предлагать выход                                                                                              | Советовать «поднять версию», не посмотрев, вышла ли она                  |
| Совет Заказчику про настройку, которую агент прочитать не может                                                       | Сказать прямо, что не проверено, и дать запасной путь: токен сессии отдаёт 403 на настройки защиты ветки                                                                                                                                              | Утверждать, что кнопка или галочка на месте                              |
| Шаг CI помечен `continue-on-error`, а сигнал пропал                                                                   | Такой шаг показывается зелёным (`conclusion: success`), след остаётся только в логе; если шаг не должен блокировать, но должен быть виден — `команда \|\| echo "::warning …"`                                                                         | Считать, что непройденный шаг останется заметным сам по себе             |
| Сборка открыта локально без стилей                                                                                    | Сайт собран с базовым путём: класть `dist` в подпапку с именем проекта и открывать `/<проект>/…`, иначе CSS и шрифты отдают 404                                                                                                                       | Решать, что сломалась вёрстка                                            |
| Правило CSS не действует, хотя написано верно                                                                         | Сравнить силу селекторов: `.nav__list span[aria-current]` сильнее, чем `.nav__list [aria-current="page"]`, и перекрывает его цвет. Проверять не глазами, а `getComputedStyle` через браузер                                                           | Править значение, которое и так не применяется                           |
| Состояние элемента проверено только на светлом фоне                                                                   | Перебрать каждую поверхность отдельно: контур фокуса `--c-ink` на тёмной заливке подвала даёт 1,36:1 и не виден. Темную поверхность проверять своим расчётом контраста                                                                                | Считать, что общий контур фокуса подходит всюду                          |
| Модификатор кнопки сломан состоянием базового класса                                                                  | `.btn:active` задавал фон, не задавая цвет текста: у `.btn--ghost` текст совпал с новым фоном. Состояние, меняющее фон, задаёт и цвет текста                                                                                                          | Проверять только основной вариант компонента                             |
| Файл отдаётся с кодом 200, а браузер его не рисует                                                                    | Разобрать и растеризовать тот файл, который уходит в репозиторий: два дефиса подряд внутри комментария XML делают SVG недопустимым, и значок молча пропадает                                                                                          | Считать код 200 доказательством того, что файл нарисован                 |
| Ответ или решение выдан по памяти, без прогона                                                                        | До подачи ответа прогнать то, чем он проверяется: разбор, растр, сборку, расчёт. Непрогнанное называть непроверенным вслух и давать запасной путь                                                                                                     | Подавать как факт то, что не прогонялось                                 |
| Горизонтальная прокрутка на узком экране                                                                              | Искать элемент с наибольшей min-content: клонировать узел в контейнер нулевой ширины и мерить. Виновником оказался `white-space: nowrap` на метке, которой в данных достались предложения                                                             | Искать виновника по внешнему виду страницы                               |
| Ширины, на которых дефект виден, записаны «по впечатлению»                                                            | Мерить каждую ширину по очереди и записывать границу: прокрутка на «Публічній інформації» шла при содержимом до 329 px и с 600 до 628 px, а не «на 320, 360 и 600»                                                                                    | Переносить список ширин из прошлой записи, не перемеряв                  |
| Эффект на CSS-прокрутке виден не у всех                                                                               | `animation-timeline: scroll()` — Chrome и Edge с 115, Safari с 26, Firefox на ноябрь 2026 только за флагом: обёртка `@supports`, вид без движения должен быть законченным                                                                             | Считать свойство общедоступным                                           |
| Итог в источнике не сходится с его же разбивкой                                                                       | Складывать перенесённые числа самому: подпись «1143,917556 га» против суммы девяти категорий 1116,638956 га                                                                                                                                           | Доверять итоговой подписи источника                                      |
| Шрифт подставился — страницу перевёрстало                                                                             | Ровнять ширину запасного шрифта `size-adjust` в отдельном `@font-face` с `local()`: на нашем тексте Inter шире Arial на 5,26 %, и это давало CLS 0,130. `preload` от этого не спасает — он не отменяет подстановку, а только раньше начинает загрузку | Чинить сдвиг от шрифта переносом `preload`                               |
| Пробел в разметке исчез при сборке                                                                                    | Задавать значимый пробел сущностью `&#32;`: сжатие HTML убирает перенос строки, видимый текст склеивается и перестаёт входить в `aria-label` — нарушение AA 2.5.3 и отказ управления голосом                                                          | Считать перенос строки в разметке пробелом в тексте                      |
| Документ больше предела чтения — «загрузить нельзя»                                                                   | Проверить, умеет ли инструмент записи брать файл с диска: предел чтения в переписку и предел записи — разные пределы. ТЗ 319 КБ загружено, хотя чтение ограничено 256 КБ                                                                              | Переносить ограничение одного действия на другое                         |
| «Инструмент ответил успехом» принято за проверку загрузки                                                             | Сверять побайтно: выгрузить документ обратно в файл и сравнить `md5sum` с копией репозитория. Поиск по базе знаний для этого не годится — указатель обновляется с задержкой                                                                           | Считать ответ инструмента доказательством содержимого                    |
| Предел записан в документе, но ничем не проверяется                                                                   | Ставить проверку в `npm run ci` в тот же день: предел «project-context.md до 100 строк» жил в ТЗ с начала и был превышен до 133 строк и 44 КБ, которые уходили в переписку при каждом старте сессии                                                   | Считать записанный предел действующим                                    |
| Рабочий процесс должен писать в защищённую `main` или запускать другой процесс своим коммитом                         | Писать в отдельную ветку; другой процесс запускать `workflow_dispatch` (`gh workflow run`) — это исключение из правила `GITHUB_TOKEN`                                                                                                                 | Ждать, что push от `GITHUB_TOKEN` пройдёт защиту или запустит `on: push` |
| Снимок после смены темы или стилей показывает «серые» карточки и бледный текст                                        | Ждать дольше `--motion-fast` (120 мс) перед снимком: иначе снята середина перехода цвета                                                                                                                                                              | Чинить цвета по такому снимку                                            |
| Сверить загрузку документа базы знаний, не читая его в переписку                                                      | `version` из ответа `project_write`/`project_read` — SHA-256 содержимого: сравнить с `sha256sum` копии. Проверено 19.11.2026 на ТЗ 3.18 вместе с `md5sum` выгрузки                                                                                    | Выгружать документ в переписку целиком ради сверки                       |
| Поиск в интернете «не нашёл» вакансию предприятия, а она есть на OLX                                                  | Поисковик объявления OLX почти не индексирует: просить у Заказчика ссылку или текст, а в ответе писать «поиском не найдено», а не «нет»                                                                                                               | Делать вывод «вакансии нет» по пустой выдаче поиска                      |
| Источник отвечает раннеру GitHub `403` с `cf-mitigated: challenge`                                                    | Это проверка Cloudflare по адресу раннера (США), заголовки не помогают: выключить источник данными, записать в `findings.md`                                                                                                                          | Обходить проверку браузером на раннере или сторонними сервисами          |
| Нужно увидеть ответ источника с раннера, а артефакты из контейнера не скачиваются (403 прокси)                        | Временный зонд на ветке, вывод в журнал: заголовки, разметка без текстов, `base64` небольшого JSON; `gh run view --log` читается                                                                                                                      | Коммитить чужие ответы в репозиторий ради осмотра                        |
| `mongodb-memory-server` не ставится или тесты БД молча пропускаются                                                   | `fastdl.mongodb.org` из контейнера агента недоступен. БД — сервисным контейнером `mongo` в CI, `REQUIRE_MONGO_TESTS=1` делает отсутствие БД ошибкой (решение 035)                                                                                     |
| Fastify: `trustProxy` числом не проходит проверку типов                                                               | Типы Fastify 5 не принимают число. Функция `(addr, hop) => hop < N` означает то же самое                                                                                                                                                              |
| `/health` висит 7 с при недоступной MongoDB                                                                           | `timeoutMS` драйвера срок проверки связи не держит. Ограничивать своим `Promise.race`, у нас 2 с                                                                                                                                                      |
| Сервис Render в монорепозитории не находит соседний пакет или lock-файл                                               | `rootDir` прячет от сборки всё вне себя (документация Render). Не задавать `rootDir`, ставить из корня: `npm ci --include=dev --workspace=server --include-workspace-root` (решение 037)                                                              | `rootDir: server`                                                        |
| Zod 4: `.partial()` и `.omit()` на схеме с `refine` бросают исключение                                                | Частичную правку накладывать на текущую запись и проверять полной схемой (решение 038)                                                                                                                                                                |
| `gh pr create` из сессии агента — 403, GraphQL закрыт                                                                 | PR через REST: `gh api repos/Butcherok/uzn-desna/pulls -f title=… -f head=… -f base=main -F body=@файл`                                                                                                                                               |
| Скрипт страницы Astro попал в HTML встроенным и политика содержимого `script-src 'self'` его не пустит                | Astro встраивает скрипты меньше 4 КБ: в `vite.build.assetsInlineLimit` функция, отдающая `false` для `.js` (решение 040)                                                                                                                              | Разрешать `'unsafe-inline'` ради одной страницы                          |
| Форма админки на сохранении без правок получает 422 по полю, которого в форме нет                                     | Поля пункта группы вне формы (`id` источника) терялись: они едут обратно ключом `__keep`; тест прогоняет все записи `data/*.json` через форму и назад                                                                                                 | Добавлять в форму скрытые поля ради сохранения                           |
| axe-core в админке не запускается из теста: `window.axe` не определён                                                 | Политика содержимого админки не пускает встроенный `<script>`: внедрять исходник через `page.evaluate(axeSource)` (CDP обходит CSP)                                                                                                                   | Ослаблять CSP ради проверки                                              |
| Коммит рабочего процесса в `main` или запуск `Deploy` коммитом не срабатывает                                         | Данные — в незащищённую ветку (`sync-data`, `content-data`), `Deploy` — явным `workflow_dispatch` (решения 023, 041)                                                                                                                                  | Токен в списке обхода защиты `main`                                      |
| Админка без конца пишет «Публікація триває», прогон на GitHub давно закончен                                          | Сервер не может спросить GitHub: в журнале Render `github run …: HTTP 401` — в `GITHUB_DISPATCH_TOKEN` не токен GitHub (`github_pat_…`); перевыпустить и вставить (решение 041)                                                                       | Путать строку выгрузки и токен GitHub                                    |
| Ссылка на маленький PDF в сборке — строка `data:application/pdf;base64,…`, а не файл                                  | Vite встраивает файлы до 4 КБ; для документов — `import.meta.glob(…, { query: '?no-inline' })` (решение 042)                                                                                                                                          |
| `POST /uploads` с файлом 2 МБ отвечает 500 `FST_REQ_FILE_TOO_LARGE`                                                   | Пределы `@fastify/multipart` — при регистрации, с `throwFileSizeLimit: false`; превышение — по `file.truncated`, текст отказа — домен (решение 042)                                                                                                   |
| Публикация «не удалась», а сайт обновился; в журнале `failed to get run: HTTP 404` или `failed to get jobs: HTTP 500` | `gh run watch` падает от любого сбоя API. Ждать прогон своим опросом `gh run view` с повтором при сбое (решение 042, повторный прогон)                                                                                                                |
| Прогон рабочего процесса сразу `failure`, задач 0, имя прогона — путь к файлу                                         | Ошибка разбора файла, например `${{ runner.temp }}` в `env` задачи: контекст `runner` есть только в шагах. Каталог — шагом через `GITHUB_ENV` (решение 045)                                                                                           |
| `mongorestore` в контейнере: `stat …: permission denied` на файле раннера; сверка дампа не находит коллекций          | Не делить файлы между раннером и контейнером: дамп и восстановление — трубой (`--archive` без файла). `mongodump` 100.x пишет имя коллекции в обратных кавычках (решение 045)                                                                         |
| Прогон с секретом подключения: `bad auth`, а значение не видно                                                        | Вывести форму строки без значения: схема, логин, длина и состав пароля, пробелы. 22.11.2026 так нашлось, что в секрет вставился чужой текст из буфера обмена вместо пароля Atlas                                                                      |
