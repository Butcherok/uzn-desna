# Уроки

Правило: симптом → что делать. 1–3 строки на урок. Перед добавлением проверить, нет ли уже.

| Симптом                                                    | Делать                                                                                                                | Не делать                                            |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Исправление «не помогло»                                   | Проверить, что открыта новая сборка: номер в подвале, кэш, проснулся ли бэкенд                                        | Следующая правка вслепую                             |
| Совет о внешнем сервисе по памяти оказался устаревшим      | Сверять с официальной документацией перед ответом                                                                     | Утверждать без проверки                              |
| Старый PowerShell не понимает `&&`                         | Команды отдельными строками                                                                                           | Цепочки через `&&`                                   |
| Ошибка API превратилась в пустой список                    | Три состояния: данные, пусто, неизвестно                                                                              | `catch` с пустым значением                           |
| Приватный репозиторий на тарифе Free                       | Сделать публичным: иначе нет ни GitHub Pages, ни защиты `main`, ни бесплатных минут Actions                           | Платить за Pro при бюджете 0                         |
| `robots.txt` проекта не действует                          | Для страниц проекта поисковики читают только корневой `robots.txt` домена; закрытие держать на `<meta name="robots">` | Считать, что `/<проект>/robots.txt` что-то запрещает |
| Интеграция фреймворка кладёт рантайм в сборку без островов | Включать интеграцию в задаче, где появится первый остров; `budget:check` считает только запрошенные страницей файлы   | Держать в сборке файл, который никто не загружает    |
