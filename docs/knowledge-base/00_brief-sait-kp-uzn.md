## 1. Заказчик и роли

- Заказчик, владелец продукта, единственный утверждающий: Шкляр Р.П. Личная инициатива.
- Разработчик: Claude в роли компании-разработчика + Роман как fullstack JS-разработчик (React, Node.js).
- Темп неравномерный, сроков нет. Бюджет 0,00 грн, только бесплатные тарифы.
- Статус сайта: внутренний показ сотрудникам. Пометок «неофициальный» нет. Решение об официальном запуске или отмене принимает руководство после готовности. До этого решения страницы закрыты от поисковиков (`noindex`).

## 2. Цель и границы

- Сайт-визитка. Услуги: описание и телефоны, без онлайн-заказа. Формы обращений нет.
- Языки: украинский (основной), английский (дополнительный).
- Админка обязательна: сначала Роман, потом сотрудник без технических навыков.
- Руководство показывается поимённо, с фото и должностями, по образцу сайтов киевских коммунальных компаний.

## 4. Точка отсчёта

- Существующая страница: https://desna.kyivzelenbud.com/ (сеть сайтов КО «Київзеленбуд», WordPress, общая тема). Меню: Про нас, Новини, Парки, Послуги, Контакти. Новый сайт её не копирует: отличия — карточки Facebook, тематическая лента, закупки, карта района, свой дизайн.
- Концепт `main-concept.webp`: картинка-настроение, не макет. Берём зелёно-бежевую палитру, иллюстрацию парка в первом экране, ряд карточек-разделов, скруглённые формы. Меняем: реальная навигация, украинская типографика, узнаваемый Деснянский район или реальные фото.
- Дизайн: 2–3 варианта главной (иллюстративный, фотографический, строгий «муниципальный»).

### 5.1. Сон Render
Факты (документация Render, 12.11.2026): сон через 15 минут без входящих запросов, пробуждение около минуты, 750 часов в месяц на рабочее пространство, запрос к `/robots.txt` сервис не будит.
1. Публичный сайт не ждёт бэкенд: новости и закупки синхронизируются по расписанию и отдаются как готовые данные. Сон заметен только в админке.
2. Будильника нет: синхронизация по расписанию в GitHub Actions, бэкенд нужен только админке (`claude/06_eksperyment-render-atlas-pinger.md`, раздел 7, п. 1). Внешний пингер и самопинг отброшены 13.11.2026.
3. Кэш синхронизации хранится в БД: память процесса на Render Free не сохраняется.

### 5.2. Новости из Facebook
- Формат карточки: заголовок (первая строка или предложение поста — у постов Facebook нет отдельного заголовка), первое фото, текст до 200 символов, ссылка на пост.
- Администратор страницы — сотрудник предприятия. Для чтения постов через API нужен токен страницы, который выдаётся от имени её администратора. Набор прав, срок жизни токена и необходимость проверки приложения Meta **[ПРОВЕРИТЬ]** тестовым приложением — первый технический эксперимент.
- Запасной вариант: официальный встраиваемый блок страницы (без своего дизайна карточек) или ручное добавление новости в админке.

### 5.3. Закупки
Публичный API Prozorro по ЄДРПОУ. Формат выдачи и лимиты **[ПРОВЕРИТЬ]** вторым экспериментом.

### 5.4. Тематическая лента
Итог эксперимента 4, решения Заказчика 13.11.2026. Полностью — `claude/08_eksperyment-tematychna-strichka.md`, разделы 4, 6, 7, 12.6.
1. Белый список: КМДА (HTML-выборка по тегу 19 «Парки та зелені зони»), Київзеленбуд головний (WP REST), The Conversation (Atom по 7 темам). Хмарочос (WP REST по 4 тематическим тегам) добавляется только после письменного разрешения редакции. RSS — запасной путь для каждого источника.
2. Исключены: сайт самого предприятия desna.kyivzelenbud.com (дубль с блоком Facebook), Слово і Діло (0 тематических материалов за 8 недель), лента Еврокомиссии (объём и тематика), Суспільне (условия использования).
3. GDELT — необязательный источник мировых новостей, выключен до удачного повторного прогона: при проверке адрес заблокирован ошибкой 429.
4. Словарь тем и стоп-слова применяются только к записям, пришедшим запасным путём через RSS; выборки по тематическим тегам в словарь не прогоняются.
5. Синхронизация — 3 раза в сутки в GitHub Actions; без ключей и секретов. Ошибка источника не очищает ленту.
6. Блок показывает последние 6–8 карточек независимо от их даты; карточки вытесняются новыми, а не удаляются по возрасту. Это условие работоспособности: объём — 1,85 карточки в неделю, 2,6 после разрешения Хмарочоса.
7. Фото источников не выводятся: прав на них нет ни у одного источника белого списка. Иллюстрация карточки — наша, по категории. Отрывок до 200 символов — только у источников, явно разрешающих частичное использование.

| CI одной командой `npm run ci` | С первого PR |
| TTL-кэш, общий Promise на параллельные вызовы, каталог ошибок, лог с маскированием секретов | С адаптацией под бэкенд |
| Формат передачи «Решено / Отброшено / Состояние / Открытые вопросы / Следующий шаг» | В инструкциях проекта |

| Делаем иначе | Причина по отчёту |
|---|---|
| ESLint, Prettier, Vitest, pre-commit — в первом PR | В боте отложили, получили долг на 190-м PR |
| Зелёный CI обязателен для merge | Публичный репозиторий это позволяет |
| Состояние проекта обновляется в том же PR, что и код | В боте документы отстали на месяц |
| Обычные слова вместо буквенных кодов в правилах | Якоря стали нечитаемы |
| Ошибка внешнего API ≠ пустой результат (данные / пусто / неизвестно) | Дефекты поведения в боте |
| Один источник правды: `docs/` в репозитории; проект Claude хранит только бриф, ТЗ, дизайн, контент | В боте правда расползлась на три места |

Не берём: самописные check-скрипты, отдельного агента-тестировщика, ветку handoff, большой опросник, всё из Rust-части, хранение в localStorage.

## 7. Риски

1. Facebook API: токен зависит от сотрудника-администратора; возможна проверка приложения Meta.
2. Бесплатные тарифы меняются; Render Free не рекомендован для продакшена.
3. Публичный репозиторий и адрес GitHub Pages доступны любому по ссылке, хотя сайт и не индексируется.
4. Передача редактору: нужна инструкция по админке и резервная копия БД по расписанию.
5. Тематическая лента держится на трёх источниках и даёт 1,85 карточки в неделю — нижняя граница полезности. Отказ одного источника или смена структуры страниц КМДА заметно опустошает блок. Резервы по порядку: разрешение Хмарочоса, районные сайты сети «Київзеленбуд», повторный прогон GDELT.
6. Сбор КМДА идёт по HTML-выборке с тегом и датами: при изменении вёрстки страницы разбор ломается, тогда как RSS этого тега не поддерживает.
