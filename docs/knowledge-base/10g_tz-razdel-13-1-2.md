### 13.1. Перечень полей по сущностям

Обозначения: **Об.** — обязательное поле; **Яз.** — языковое поле вида `{ uk, en }` (6.1, п. 4); предел длины — в знаках. У каждой редактируемой сущности, кроме явно указанных, есть служебные поля `_id`, `createdAt`, `updatedAt`, `deletedAt`, `status` (6.1, пп. 3, 5, 7) — в таблицах они не повторяются.

**Состав схемы версии 1** (решение Заказчика 15.11.2026). Схема версии 1 описывает только поля версии 1. Служебные поля записи БД (`_id`, `status`, `createdAt`, `updatedAt`, `deletedAt`) в выгрузку для публичных страниц (6.6) не идут: публичным страницам они не нужны, а `_id` наружу не выводится вовсе (6.1, п. 2).
