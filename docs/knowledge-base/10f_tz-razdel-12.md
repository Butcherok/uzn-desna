## 12. Приёмка

### 12.1. Критерий закрытия задачи

Задача закрыта, когда выполнены все шесть условий:
1. Результат проверен разработчиком самостоятельно: тесты, сборка, открытие страницы или вызов эндпоинта. Заказчику отдаётся только недоступное разработчику (чужие кабинеты, секреты, подтверждения людей) — 12.6.
2. `npm run ci` зелёный, PR зелёный.
3. `docs/project-context.md` обновлён в том же PR; решение по коду, если оно было, записано в `docs/decisions/` там же.
4. Найденное попутно записано и показано Заказчику, но не сделано (инструкции проекта, п. 4).
5. Заглушка, которая закрылась в ходе задачи, убрана из текста ТЗ и из реестра 13.2 тем же PR или той же правкой ТЗ.
6. Заказчик сказал «принято».

Не является закрытием: «собралось», «тесты зелёные», «выложено». Версия состава закрыта, когда пройден её чек-лист целиком и каждый непройденный пункт либо исправлен, либо перенесён решением Заказчика с записью в 13.3.
