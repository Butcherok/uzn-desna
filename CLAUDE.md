# CLAUDE.md — правила агента (всегда в контексте)

Проект: сайт-визитка КП УЗН Деснянського району. Репозиторий: `Butcherok/uzn-desna` (публичный). Владелец: Roman. Бюджет 0 грн.

## Экономия лимитов

- Читать только файлы под задачу. Один и тот же файл не перечитывать.
- План до 5 пунктов → действие или один пакет вопросов.
- Логи и вывод команд — в файл, в ответе только итог.
- Правка — точечная, без переписывания файла целиком.

## Старт сессии

1. `docs/project-context.md` — состояние и следующий шаг.
2. `docs/roadmap.md` — только если неясно, что в работе.
3. Дальше — только файлы под задачу. Весь репозиторий не обходить.

## Источник правды

`docs/` на ветке `main`. Задача не закрыта, пока `docs/project-context.md` не обновлён в том же PR, что и код.

## Запреты

- Код, коммиты, PR — только после явного «да» владельца. Обсуждение не является разрешением.
- Секреты, токены, `.env` — не в чат и не в git.
- Не чинить попутно найденное вне задачи: записать и показать владельцу.
- Платные сервисы не подключать.
- Merge в `main` делает только владелец.

## Git

- Одна задача в работе. Одна задача = одна ветка = один PR.
- Ветки: `feat/<тема>`, `fix/<тема>`, `docs/<тема>`, `chore/<тема>`.
- Коммиты: Conventional Commits с областью, на английском. Пример: `feat(news): add facebook sync job`.
- PR: «Что сделано», «Что нарочно не тронуто», «Как проверить».
- Перед PR: `npm run ci` зелёный.

## Проверка

- Проверяет агент: линтер, типы, тесты, сборка, открытие страницы.
- «Исправление не помогло» → сначала убедиться, что проверяется новая сборка (номер сборки в подвале сайта, кэш GitHub Pages, проснулся ли Render). Потом одна гипотеза за раз. Две неудачные правки подряд — стоп и разбор.
- Ошибка внешнего API не равна пустому результату: различать «данные», «пусто», «неизвестно».

## Внешние сервисы

Факты о Render, GitHub Pages, MongoDB Atlas, Meta Graph API, Prozorro, Cloudinary перепроверять по официальной документации перед использованием. Не подтверждено — сказать прямо.

## Общение

- С владельцем — по-русски. Контент сайта — украинский и английский. Код — английский.
- Уточнения — одним пакетом.
- Шаги для владельца: где → что ввести или нажать → что должно появиться → когда остановиться. Команды PowerShell — отдельными строками, без `&&`.
- Конец задачи: статус → один следующий шаг с алгоритмом → что записано в `docs/`.

## Уроки и решения

- Новая ошибка или удачный обход → 1–3 строки в `docs/lessons-learned.md` (сначала проверить, нет ли уже).
- Принятое решение → файл в `docs/decisions/` по шаблону `000-template.md`.
